# 단백하게 (Way to Go) 홈 화면 시안

하루 단백질 기록 앱의 홈 화면 18개를 비교하는 React 프로토타입입니다. 갤러리에서 시안을 선택하면 실제 크기로 열립니다. 화면의 **소스코드**에서 그룹별 React와 CSS를 읽거나 내려받을 수 있습니다.

## 실행

저장소 루트에서 실행합니다.

```sh
npx vite --config prototypes/way-to-go-home/vite.config.ts
```

[로컬 갤러리](http://127.0.0.1:5180/prototypes/way-to-go-home/)를 엽니다. 시안 상세에서 이전·다음 버튼이나 좌우 화살표로 이동할 수 있습니다. 선택한 시안은 URL 해시로 바로 열 수 있습니다.

## 비교 방법

- 기본 상태는 오늘 기록 85g, 목표 120g입니다. 예시 상태 메뉴에서 0g, 24g, 85g, 108g, 120g을 선택할 수 있습니다.
- 새로 입력하거나 수정한 기록은 시안 사이에서 공유됩니다. 예시 상태를 바꾸거나 브라우저를 새로고침하면 샘플 기록을 다시 불러옵니다.
- 빠른 기록, 끼니 추정, 직접 입력, 기록 수정·삭제·되돌리기를 체험할 수 있습니다. 목표를 달성하면 카드 PNG를 내려받을 수 있습니다.

| 파일 | 시안 |
| --- | --- |
| `concepts/utility.tsx` | 숫자 하나, 고단백 듀오, 3초 기록, 끼니별 기록, 다음 한 끼 |
| `concepts/mascot.tsx` | 낙서네 헬스장, 밈 냉장고, 근육 적금, 근육냥 퀘스트, 헬스장 두 컷 |
| `concepts/graphic.tsx` | 쉐이커 충전, 오늘의 단백질 접시, 단백질 영수증, 단백질 계기판, 10g 단백질 블록 |
| `concepts/rhythm.tsx` | 저녁 체크인, 일주일의 리듬, 단백질 계수기 |
